# Local typography

The app serves these fonts from the same origin; no visitor requests go to a font provider.

- **CTPM Display**: modified Latin subset of [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), normal and italic variable weights 300–700.
- **CTPM Sans**: modified Latin subset of [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), variable weights 200–800.

Originals were downloaded from the Google Fonts repository on November 24, 2026 UTC. The fontTools subset retains Latin/extended Latin, common punctuation, currency and supported navigation symbols. Font family, full-name, unique-name and PostScript-name entries were renamed for the modified files. Files use WOFF compression, preserve variable weight axes, and retain their original copyright/license metadata. Other scripts and missing symbols use the system fallback fonts.

The original SIL Open Font License texts are included as `cormorantgaramond-OFL.txt` and `manrope-OFL.txt`. The fonts are free to use under those licenses; no font subscription is required. See `/refinement.css` for the font-face declarations and display behavior.
