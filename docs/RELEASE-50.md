# Handover release: 50 built-in improvements

These improvements use the existing Render service, SQLite, browser capabilities, and open-source libraries. No paid add-on is required. Render hosting/storage remains the owner's existing subscription. External email and fee-based checkout are disabled by default. Existing financial history is preserved.
