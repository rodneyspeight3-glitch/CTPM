# Property slideshows and lively accents

Property cards on Home, Available homes, saved property views, and staff dashboards now show uploaded cover and gallery pictures in a horizontal slideshow. Public and staff property detail dialogs use the same controls. A house with one image keeps its single photo and an expand control; previous/next, dots and play controls appear only when more photographs exist. Gallery-only houses show their uploaded images instead of an unrelated placeholder. The uploaded cover is excluded from the gallery sequence when its bytes match an existing gallery photograph, so promoting a cover does not duplicate that photo.

Use previous/next, dots, Left/Right/Home/End keys, or a horizontal touch swipe. The larger photo viewer fits photographs without cropping, shows captions and thumbnails, supports Escape to close, and returns focus to its trigger. Manual navigation pauses automatic play. Play/Pause is explicit; optional automatic card movement occurs every 6.5 seconds only while the image is visible and not being interacted with. It pauses under a dialog, outside the viewport, and in background tabs. Reduced-motion, quiet mode, and data-saving preferences disable automatic movement. All navigation remains available. One failed image can be skipped with the same controls, and unavailable metadata leaves the original photo usable.

Existing gallery ordering, cover replacement, uploads, availability rules and photo permissions remain authoritative. No sample records, generated property photographs, external image libraries or paid services are added. Gallery changes refresh card slides. Preview and unavailable/private photos retain the existing access checks; assigned tenants retain their existing access.

The visual refresh uses coral, berry, warm gold and lilac over light reading surfaces, with matching night colors. Alternative palettes, visitor timezone-based day/night behavior, high contrast, reading settings, reduced motion, and the existing moving building background remain available.

Photo downloads use random app-generated filenames. Gallery descriptions supplied by staff remain editable; old labels without a review marker are replaced in public and staff DTOs by an automatic photo label until reviewed. This prevents earlier filename-based captions appearing in the viewer. See [PHOTO-NAMES.md](PHOTO-NAMES.md).
